# Funcionalidades

Cada pasta pertence a um assunto do ERP. Configurações, componentes e hooks
exclusivos ficam dentro do assunto correspondente. O diretório não indica que
uma funcionalidade está pronta ou integrada.

Consulte o [mapa de responsabilidades](../../../../architecture/README.md#onde-encontrar-uma-funcionalidade)
e o registro verificável em `architecture/structure.json` antes de criar uma pasta.
