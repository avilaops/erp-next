# Planos e especificações de desenvolvimento

[Voltar às telas](../README.md)

Os diretórios `plans` e `specs` preservam o planejamento técnico de cada etapa. Um plano descreve trabalho previsto; a presença de uma tarefa aqui não comprova sua implementação ou publicação.

Para consultar o comportamento de uma tela, use o [manual por tela](../README.md). Os caminhos dos planos foram mantidos para preservar as referências de desenvolvimento.
