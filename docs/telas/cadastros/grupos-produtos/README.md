# Grupos de produtos

[Todas as telas](../../../README.md) · [Cadastros](../README.md)

Manter os grupos de produtos da empresa.

**Onde acessar:** `/cadastros/grupos-produtos`.

## O que aparece na tela

- Código e nome
- Situação e observação

## O que você pode fazer

- Buscar, criar e editar
- Arquivar ou reativar

## Regras e limites

Criar um grupo não significa que todos os produtos já estejam associados a ele.
