# Listas de preços

[Todas as telas](../../../README.md) · [Cadastros](../README.md)

Manter listas de preços e seus itens, separadas da publicação da tabela comercial calculada.

**Onde acessar:** `/cadastros/listas-precos`.

## O que aparece na tela

- Identificação e situação da lista
- Produtos e preços dos itens

## O que você pode fazer

- Consultar listas
- Criar e editar conforme as permissões

## Regras e limites

Para calcular uma tabela a partir de custos e parâmetros comerciais, use Preferências → Tabela de preços.
