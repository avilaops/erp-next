# Tags

[Todas as telas](../../../README.md) · [Cadastros](../README.md)

Manter as tags e sua relação com um grupo.

**Onde acessar:** `/cadastros/tags`.

## O que aparece na tela

- Código e nome
- Grupo de tags
- Situação e observação

## O que você pode fazer

- Buscar, criar e editar
- Arquivar ou reativar

## Regras e limites

O cadastro de tags não atribui classificações automaticamente aos registros existentes.
