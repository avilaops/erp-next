# Check-in de recebimentos

[Todas as telas](../../../README.md) · [Compras](../README.md)

Conferir os recebimentos relacionados às compras.

**Onde acessar:** `/compras/recebimentos`.

## O que aparece na tela

- Compra e fornecedor
- Itens e quantidades recebidas
- Situação e referências

## O que você pode fazer

- Consultar o recebimento
- Conferir e registrar as ações disponíveis

## Regras e limites

O recebimento é uma etapa explícita. A importação de XML não substitui a conferência física.

## Referências para manutenção

Guia conferido no código de 12/11/2026. As ações dependem das permissões e da configuração da empresa. Relatos técnicos antigos descrevem a etapa em que foram escritos.
