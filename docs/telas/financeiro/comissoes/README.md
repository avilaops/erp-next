# Comissões

[Todas as telas](../../../README.md) · [Financeiro](../README.md)

Consultar e manter os registros de comissão autorizados.

**Onde acessar:** `/financeiro/comissoes`.

## O que aparece na tela

- Vendedor, pedido e referência
- Valor, ajuste e situação

## O que você pode fazer

- Consultar comissões
- Registrar os ajustes permitidos
- Conferir o vínculo com o pedido

## Regras e limites

Comissão registrada não representa pagamento bancário realizado.

## Referências para manutenção

Guia conferido no código de 12/11/2026. As ações dependem das permissões e da configuração da empresa. Relatos técnicos antigos descrevem a etapa em que foram escritos.
