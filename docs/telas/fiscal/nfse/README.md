# NFS-e recebidas

[Todas as telas](../../../README.md) · [Fiscal](../README.md)

Consultar e importar os documentos de serviço recebidos suportados pelo ERP.

**Onde acessar:** `/fiscal/nfses`, `/servicos/notas`.

## O que aparece na tela

- Arquivo e identificação da NFS-e
- Prestador, valores e situação

## O que você pode fazer

- Consultar e importar documentos conforme o formato aceito

## Regras e limites

Importar uma NFS-e recebida não emite uma nota de serviço. Confira os formatos e provedores aceitos na própria tela.
