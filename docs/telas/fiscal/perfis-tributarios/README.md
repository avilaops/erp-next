# Perfis tributários

[Todas as telas](../../../README.md) · [Fiscal](../README.md)

Manter modelos de declaração tributária para reutilização consciente no rascunho fiscal.

**Onde acessar:** `/preferencias/cadastros/perfis-tributarios`.

## O que aparece na tela

- Identificação, aplicação e campos tributários do perfil

## O que você pode fazer

- Consultar e manter os perfis
- Aplicar e revisar os dados no documento

## Regras e limites

O perfil precisa ser compatível com a empresa e a operação. Valores gerenciais do simulador não substituem uma declaração tributária.
