# Assistente e ajuda

[Todas as telas](../../../README.md) · [Início e navegação](../README.md)

Consultar a ajuda e usar o assistente dentro das capacidades e permissões disponíveis.

**Onde acessar:** `/assistente`, `/ajuda`.

## O que aparece na tela

- Consulta e resposta do assistente
- Conteúdo de ajuda

## O que você pode fazer

- Consultar a ajuda
- Enviar uma pergunta ao assistente

## Regras e limites

Uma resposta do assistente não comprova uma gravação ou operação no ERP. Confira as ações e os resultados nas telas relacionadas.
