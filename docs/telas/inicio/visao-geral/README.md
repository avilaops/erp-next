# Visão geral e dashboards

[Todas as telas](../../../README.md) · [Início e navegação](../README.md)

Acompanhar as informações da empresa e acessar os módulos do ERP.

**Onde acessar:** `/`, `/dashboard`, `/dashboards`.

## O que aparece na tela

- Empresa ativa
- Indicadores e atalhos
- Dashboards por assunto

## O que você pode fazer

- Abrir um módulo
- Consultar a visão geral ou um dashboard específico
- Usar a busca do ERP para localizar telas

## Regras e limites

Dados exibidos dependem da empresa ativa, da fonte e das permissões de consulta.
