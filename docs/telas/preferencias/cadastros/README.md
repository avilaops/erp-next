# Configurações de cadastros

[Todas as telas](../../../README.md) · [Preferências](../README.md)

Manter as configurações de produtos, pessoas e tipos de contato.

**Onde acessar:** `/preferencias/cadastros/clientes-fornecedores`, `/preferencias/cadastros/produtos` e `/preferencias/cadastros/tipos-contatos`.

## O que aparece na tela

- Configurações de clientes e fornecedores
- Configurações de produtos
- Tipos de contatos

## O que você pode fazer

- Consultar e salvar cada configuração autorizada

## Regras e limites

Os perfis tributários têm guia próprio. Uma configuração não deve ser interpretada como preenchimento automático de todos os cadastros anteriores.
