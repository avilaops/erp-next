# Configurações financeiras

[Todas as telas](../../../README.md) · [Preferências](../README.md)

Definir as preferências financeiras disponíveis para pagamentos e recebimentos.

**Onde acessar:** `/preferencias/financeiro`.

## O que aparece na tela

- Meio de pagamento sugerido para baixas manuais

## O que você pode fazer

- Consultar e salvar a configuração autorizada

## Regras e limites

A sugestão de meio de pagamento não confirma uma baixa. Conta Digital e integrações bancárias têm limites próprios.
