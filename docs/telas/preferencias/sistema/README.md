# Sistema e ferramentas

[Todas as telas](../../../README.md) · [Preferências](../README.md)

Ajustar a aparência e manter as ferramentas de configuração do sistema.

**Onde acessar:** `/preferencias/sistema`.

## O que aparece na tela

- Interface e quantidade de produtos por página
- Arquivos
- Campos customizados
- Transições
- Modelos de relatórios e etiquetas

## O que você pode fazer

- Salvar as preferências disponíveis
- Abrir cada ferramenta pela categoria Sistema

## Regras e limites

Cadastrar uma definição de campo, relatório ou etiqueta não garante sua utilização em todos os fluxos. Confira o suporte exibido pela própria ferramenta.
