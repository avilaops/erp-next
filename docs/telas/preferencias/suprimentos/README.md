# Configurações de estoque e compras

[Todas as telas](../../../README.md) · [Preferências](../README.md)

Manter as regras de suprimentos apresentadas nas telas de Estoque e Compras.

**Onde acessar:** `/preferencias/suprimentos/estoque` e `/preferencias/suprimentos/compras`.

## O que aparece na tela

- Configurações de estoque
- Configurações de pedidos de compra

## O que você pode fazer

- Consultar e salvar as configurações autorizadas
- Acessar depósitos, grupos e tags

## Regras e limites

Os cadastros de depósitos, grupos e tags têm telas próprias. Alterar configuração não executa um recebimento ou movimentação de estoque.
