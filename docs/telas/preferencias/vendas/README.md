# Configurações de vendas

[Todas as telas](../../../README.md) · [Preferências](../README.md)

Manter as exigências usadas na confirmação dos pedidos.

**Onde acessar:** `/preferencias/vendas`.

## O que aparece na tela

- Valor mínimo
- Prazo máximo
- Exigência de contato do cliente
- Demais regras exibidas na tela

## O que você pode fazer

- Consultar e salvar regras
- Conferir o efeito ao confirmar o pedido

## Regras e limites

Um pedido pode ser salvo e ainda ter pendências para confirmação. As configurações comerciais de custos e margens ficam em Parâmetros comerciais.
