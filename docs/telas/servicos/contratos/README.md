# Contratos e modelos

[Todas as telas](../../../README.md) · [Serviços](../README.md)

Preparar e acompanhar contratos vinculados aos clientes e pedidos.

**Onde acessar:** `/servicos`, `/servicos/contratos`.

## O que aparece na tela

- Cliente, pedido e modelo
- Conteúdo e dados do contrato
- Versão e situação

## O que você pode fazer

- Consultar e preparar contratos
- Manter os modelos autorizados
- Revisar o conteúdo e executar as ações disponíveis

## Regras e limites

Contrato utiliza os dados registrados para sua versão. Criar um contrato não equivale a uma assinatura ou envio confirmado.
