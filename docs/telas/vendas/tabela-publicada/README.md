# Tabela publicada

[Todas as telas](../../../README.md) · [Vendas](../README.md)

Consultar os preços e condições de uma versão comercial já publicada.

**Onde acessar:** `/vendas/tabela-precos`.

## O que aparece na tela

- Linha e versão
- Busca por equipamento ou código
- Destino e condição de inscrição estadual
- Preços e limites comerciais exibidos para o perfil de acesso

## O que você pode fazer

- Filtrar os equipamentos
- Conferir preços e alçadas
- Ir para o simulador

## Regras e limites

Esta tela consulta a versão publicada. Preparar e confirmar uma versão nova ocorre em Preferências → Tabela de preços.
